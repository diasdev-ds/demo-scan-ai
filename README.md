# demo-scan-ai — распознавание документов в 1С

**Задача.** Бухгалтерия вручную вбивает данные со сканов накладных и счетов.

**Что делает.** Принимает PDF и фото документов, распознаёт через GPT-4 Vision,
извлекает номер, дату, контрагента, БИН/ИИН и позиции таблицы, выгружает в Excel
и отправляет в 1С через REST. Приём документов — через Telegram-бота.

Поддержаны документы на русском и казахском. В репозитории лежит пример результата —
`результат_20260621_154400.xlsx`.

| Файл | Назначение |
|---|---|
| `process_docs.py` | Распознавание через GPT-4 Vision, выгрузка в Excel |
| `extractor.py` | Разбор PDF постранично |
| `sender_1c.py` | Отправка в 1С |
| `mock_1c_server.py` | Мок 1С для отладки без боевой базы |
| `telegram_bot.py` | Приём документов от пользователя |
